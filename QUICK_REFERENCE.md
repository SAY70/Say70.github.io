## 🚀 How to Use

1. **Page Load**: Animations trigger automatically
2. **Scroll**: Elements fade in as they come into view
3. **Hover**: Buttons and cards respond to mouse interaction
4. **Classes**: Apply animation classes to any element

### Example Usage:
```html
<!-- Fade in animation -->
<div class="fade-in-up">Content here</div>

<!-- Hover lift effect -->
<div class="hover-lift-more">Content</div>

<!-- Glassmorphic card -->
<div class="glass-card">Card content</div>

<!-- Gradient button -->
<button class="btn-enhanced">Click me</button>
```
